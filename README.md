# 🎬🎮 MyArchive

یک آرشیو شخصی و خودمیزبان برای **فیلم، سریال و بازی**. اسم یک عنوان را جست‌وجو می‌کنید، از بین نتایج انتخابش می‌کنید و پوستر، سال انتشار، خلاصه و لینک آن به‌صورت خودکار ذخیره می‌شود. کنار هر مورد هم می‌توانید یادداشت شخصی خودتان را بنویسید (مثلاً «تمام شد»، «۸/۱۰»، «دوباره در حال بازی»).

با PHP ساده و SQLite نوشته شده است. دیتابیس فقط یک فایل داخل پروژه است و نیازی به MySQL ندارد.

## ✨ ویژگی‌ها

- **جست‌وجوی زنده و افزودن با یک کلیک:** هم‌زمان در فیلم/سریال و بازی جست‌وجو می‌کند و نتایج را نشان می‌دهد.
  - فیلم و سریال: [TMDb](https://www.themoviedb.org/)
  - بازی: [RAWG](https://rawg.io/), به‌علاوه PlayStation Store و Epic Games Store (این دو غیررسمی هستند، پایین‌تر توضیح داده شده)
  - می‌توانید آدرس صفحه فیلم/سریال در TMDb را هم مستقیم در کادر جست‌وجو پیست کنید.
- **یادداشت و عنوان قابل ویرایش:** روی عنوان کارت کلیک کنید تا ویرایشش کنید و یادداشت شخصی را هر وقت خواستید تغییر دهید.
- **فیلتر و جست‌وجو در آرشیو:** سوئیچ بین فیلم‌ها و بازی‌ها و جست‌وجوی زنده در عنوان‌ها.
- **ایمپورت از اکسل:** یک فایل `.xlsx` یا `.csv` را بکشید و رها کنید. ستون اول عنوان و ستون دوم یادداشت است. برای هر ردیف پوستر و اطلاعات به‌صورت خودکار پیدا می‌شود و عنوان‌های تکراری رد می‌شوند.
- **بهینه‌سازی پوستر:** پوسترها یک بار دانلود می‌شوند، با نسبت ۲:۳ برش می‌خورند، کوچک می‌شوند و به‌صورت WebP در `cache/img/` ذخیره می‌شوند. بعد از آن صفحه مستقیم همان فایل کوچک و کش‌شده را بارگذاری می‌کند.
- **پشتیبان‌گیری امن:**
  - پشتیبان روزانه (تأییدشده) به‌صورت خودکار
  - پشتیبان خودکار قبل از هر حذف گروهی، ایمپورت یا بازیابی
  - اگر فایل دیتابیس خراب شود، کنار گذاشته می‌شود و جدیدترین پشتیبان سالم به‌صورت خودکار بازیابی می‌شود
  - امکان کپی همه پشتیبان‌ها در یک پوشه یا درایو دیگر
  - صفحه مدیریت پشتیبان‌ها: ساخت، دانلود، بازیابی و خروجی JSON
- **تم تیره و روشن** با ذخیره انتخاب شما.
- **فونت فارسی:** با فونت میخک (Mikhak) و وزیرمتن.

## 📋 پیش‌نیازها

- PHP نسخه **۸.۰ یا بالاتر**
- افزونه‌های PHP:
  - `pdo_sqlite` (دیتابیس)
  - `curl` (ارتباط با TMDb، RAWG و ...)
  - `gd` با پشتیبانی WebP (بهینه‌سازی پوستر؛ بدون آن پوسترها از آدرس اصلی نمایش داده می‌شوند)
  - `zip` (خواندن فایل‌های `.xlsx`)
  - `pdo_mysql` (اختیاری، فقط برای انتقال داده از دیتابیس MySQL قدیمی)
- کلید API برای TMDb و RAWG (رایگان، پایین‌تر توضیح داده شده)
- دسترسی اینترنت

همه این‌ها در XAMPP به‌صورت پیش‌فرض یا با یک تغییر ساده در `php.ini` فعال می‌شوند.

## 🚀 راه‌اندازی با XAMPP

1. **نصب XAMPP** از [apachefriends.org](https://www.apachefriends.org/) (نسخه‌ای با PHP ‏۸.۰ یا بالاتر).

2. **کپی پروژه در `htdocs`** با نام پوشه `media-tracker`:

   ```
   C:\xampp\htdocs\media-tracker
   ```

   مطمئن شوید `index.php` در مسیر `htdocs/media-tracker/index.php` قرار دارد.

3. **فعال‌سازی افزونه‌ها.** در XAMPP Control Panel روی **Config** کنار Apache کلیک کنید، `PHP (php.ini)` را باز کنید و مطمئن شوید این خطوط کامنت نشده‌اند (بدون `;` در ابتدا):

   ```ini
   extension=curl
   extension=gd
   extension=zip
   extension=pdo_sqlite
   ```

4. **گرفتن کلیدهای API** (رایگان) و گذاشتن آن‌ها در `config/config.php`:

   ```php
   define('TMDB_API_KEY', 'YOUR_TMDB_KEY');   // https://www.themoviedb.org/settings/api
   define('RAWG_API_KEY', 'YOUR_RAWG_KEY');   // https://rawg.io/apidocs
   ```

5. **روشن کردن Apache** از XAMPP Control Panel. به MySQL نیازی نیست.

6. **باز کردن برنامه** در <http://localhost/media-tracker/>.

دیتابیس (`data/media.sqlite`) در اولین بارگذاری صفحه خودکار ساخته می‌شود. اگر خواستید می‌توانید `install.php` را هم باز کنید تا آماده بودن آن را ببینید.

## 📥 ایمپورت از اکسل

1. در صفحه اصلی روی دکمه ایمپورت کلیک کنید (یا <http://localhost/media-tracker/import.php> را باز کنید).
2. فایل `.xlsx` یا `.csv` را انتخاب کنید یا بکشید و رها کنید. ردیف اول باید عنوان ستون‌ها باشد.
3. نوع همه ردیف‌ها را انتخاب کنید (فیلم یا بازی)، پیش‌نمایش را ببینید و شروع کنید.

ستون اول به‌عنوان عنوان و ستون دوم به‌عنوان یادداشت استفاده می‌شود. هر ردیف جداگانه در TMDb یا RAWG جست‌وجو می‌شود و نتیجه در گزارش زنده نشان داده می‌شود: اضافه شد، تکراری بود (رد شد) یا ناموفق بود. اگر تطابقی پیدا نشود، مورد بدون پوستر ذخیره می‌شود.

همچنین اگر قبلاً پوسترهایی در آرشیو دارید، با باز کردن `warm-cache.php` (یا اجرای `php warm-cache.php`) می‌توانید همه پوسترها را یک‌جا بهینه و کش کنید تا اولین بارگذاری صفحه سریع باشد.

## 💾 پشتیبان‌گیری

صفحه پشتیبان‌ها در <http://localhost/media-tracker/backup.php> است. این صفحه فقط از روی همان کامپیوتر (`localhost`) در دسترس است.

| قابلیت | توضیح |
|---|---|
| ساخت پشتیبان دستی | یک نسخه تأییدشده از دیتابیس می‌سازد |
| دانلود | دانلود هر پشتیبان یا نسخه فعلی دیتابیس |
| بازیابی | قبل از بازیابی، داده فعلی هم پشتیبان‌گیری می‌شود |
| خروجی JSON | همه آیتم‌ها در یک فایل JSON |
| انتقال از MySQL | کپی یک‌باره داده‌های نسخه قدیمی (در صورت وجود) |

پشتیبان‌ها در `data/backups/` نگه‌داری می‌شوند: ۳۰ پشتیبان روزانه اخیر و ۴۰ پشتیبان اخیر از انواع دیگر. برای محافظت واقعی در برابر خرابی دیسک، مسیر یک درایو یا پوشه دیگر (مثلاً پوشه Dropbox) را در `BACKUP_MIRROR_DIR` بگذارید.

## ⚙️ تنظیمات

همه تنظیمات در `config/config.php` هستند:

| ثابت | توضیح |
|---|---|
| `TMDB_API_KEY` | کلید TMDb برای فیلم و سریال |
| `RAWG_API_KEY` | کلید RAWG برای بازی |
| `DEBUG_EXTERNAL_APIS` | ثبت درخواست و پاسخ سرویس‌های خارجی در `debug.log` |
| `DB_FILE` / `DATA_DIR` | مسیر فایل دیتابیس (پیش‌فرض `data/media.sqlite`) |
| `BACKUP_DIR` | پوشه پشتیبان‌ها |
| `BACKUP_MIRROR_DIR` | (اختیاری) کپی همه پشتیبان‌ها در مسیر دیگر |
| `LEGACY_MYSQL_IMPORT`, `DB_*` | فقط برای انتقال یک‌باره از MySQL قدیمی |

## ⚠️ نکات مهم

- **کلید API را در مخزن عمومی نگذارید.** اگر پروژه را روی GitHub می‌گذارید، کلیدهای واقعی را از `config/config.php` پاک کنید و یک فایل نمونه (مثلاً `config.example.php`) بگذارید. اگر کلیدی قبلاً در جایی منتشر شده، آن را در سایت TMDb/RAWG بازسازی (regenerate) کنید.
- فایل‌های `debug.log`، پوشه `data/` (دیتابیس شخصی شما) و `cache/` را در `.gitignore` بگذارید. `debug.log` آدرس کامل درخواست‌ها را شامل می‌شود و کلید API هم داخل آن ثبت می‌شود.
- **برنامه احراز هویت ندارد.** هر کسی که به آن دسترسی داشته باشد می‌تواند آیتم‌ها را اضافه، ویرایش و حذف کند. فقط روی کامپیوتر خودتان یا شبکه خصوصی مطمئن استفاده کنید. صفحه `backup.php` به‌طور پیش‌فرض فقط از localhost باز می‌شود.
- جست‌وجوی **PlayStation Store** و **Epic Games** غیررسمی است (به‌ترتیب خواندن صفحه عمومی و یک endpoint بدون مستندات). ممکن است بدون اطلاع قبلی از کار بیفتد. در این صورت فقط نتایج RAWG نمایش داده می‌شود و بقیه برنامه سالم می‌ماند. برای عیب‌یابی `DEBUG_EXTERNAL_APIS` را روشن کنید و `debug.log` را ببینید.
- بعد از اتمام عیب‌یابی `DEBUG_EXTERNAL_APIS` را خاموش کنید تا `debug.log` بزرگ نشود.
- حذف یک آیتم تکی از روی کارت پشتیبان نمی‌گیرد. اگر نگران هستید، قبلش یک پشتیبان دستی بسازید. (حذف گروهی «همه فیلم‌ها/بازی‌ها» همیشه قبل از اجرا پشتیبان می‌گیرد.)
